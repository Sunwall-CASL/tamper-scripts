
# README for neurons-image-drop-insert.user.js

## What it does

This userscript enhances the rich-text editors on the **Ivanti Neurons ITSM platform** (targeting URLs matching `https://uwm-amc.ivanticloud.com/*`).

It adds a custom keyboard shortcut to:
1.  Open a pop-up window that supports **drag-and-drop image insertion**.
2.  Insert the dropped image directly into the editor at your cursor position.
3.  The inserted image is able to be **resized**.

## Installation

[Install this script](https://github.com/Sunwall-CASL/tamper-scripts/raw/refs/heads/main/neurons-image-drop-insert/neurons-image-drop-insert.user.js)

## Using it

 Navigate to Neurons.
*   Place your cursor inside any rich-text editor (e.g., in an email body or description field) where you want the image to go.
*   Press **Ctrl+Shift+I (Mac + Windows)** to generate the pop-up window.
*   Click and drag an image file from your computer and drop it into the pop-up window.
*   The pop-up window will automatically close, and the image will be placed where your cursor was.
*   If you need to **resize** the image, simply select a corner handle and resize the image.
